# Supported formats

The audiobook workflow accepts MP3, M4A, AAC, WAV, FLAC, OGG, and Opus inputs and creates an AAC-encoded M4B with optional JPEG, PNG, or WebP cover input. Exact decoding support depends on the FFmpeg build installed at runtime.

Vertiku does not bypass DRM. Version 1 includes no yt-dlp and no remote URL input. Vertiku is independent of Pulliku.
